**TL;DR:** The board now opens with **how the sprint is going**, and **Copy standup** turns that into a standup you can paste into Teams or Discord in one click.

## New

- **Health strip** tells the sprint's story: days left, open, needs attention, merged and median time to merge, each with a short note.
- **Copy standup** at the end of the strip: what merged since the last working day, then what's blocked, what needs attention and what's in review, with a link to each PR.
- **Pastes cleanly**: Teams gets bold headings, lists and PR links. Discord and plain-text places get Markdown.
- **Says what it copied**, like "Copied: 3 merged, 3 blocked, 3 need attention, 5 in review".
- **The whole team's numbers**: author chips, search and snoozes change the tables and the Sweep, never the strip or the standup.
- **The portable exe tells you when a new version is out**: click **Download** in the top bar to get it from GitHub.

## Heads up

- **First refresh after updating is a full one**: the cache format changed. A few seconds longer, once.
- **The sprint-end warning moved** from the Sweep header into the strip.
- **Copy standup only shows when the board includes today**, so it's hidden on past and future sprints.
- **Monday's standup covers since Friday**: "merged since" counts from the previous weekday.
- **Slack hasn't been tried yet**: it gets the same formatted version as Teams.
- **Portable copies announce new versions from this release on**, so download this one by hand.

## Getting it

Installed copies update themselves. When the top bar says **Restart to update**, click it. The portable exe doesn't update itself: download the new one from this page.
